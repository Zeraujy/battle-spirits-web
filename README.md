## Battle Spirits Eternal Simulator

Um simulador não oficial de **Battle Spirits**, criado para reunir jogadores, facilitar testes de decks e tornar o jogo mais acessível através do navegador.

O projeto está em desenvolvimento contínuo, recebendo novas cartas, melhorias de interface, recursos online e suporte progressivo às mecânicas do card game.

> Projeto independente feito por fã. Não possui afiliação oficial com a Bandai.

---

## Jogar agora

Acesse o simulador diretamente pelo navegador:

### [Battle Spirits Eternal Simulator](https://battle-spirits-web.zeraujyalkan.workers.dev/)

Não é necessário instalar nada.

---

## Sobre o projeto

O **Battle Spirits Eternal Simulator** nasceu com o objetivo de criar uma experiência moderna para quem quer jogar, testar decks e conhecer melhor o Battle Spirits original.

A proposta é reunir em um único lugar:

- Simulador de partidas
- Deck Builder
- Database de cartas
- Partidas online
- Perfil de jogador
- Personalização de interface
- Suporte progressivo às mecânicas do jogo

O projeto busca manter a identidade e a dinâmica de Battle Spirits enquanto adapta a experiência para o ambiente digital.

---

## Principais recursos

### Simulador de partidas

O simulador possui suporte para partidas locais e online, com uma interface própria para acompanhar o fluxo completo da partida.

Entre os sistemas disponíveis estão:

- Turnos e fases
- Life
- Reserve
- Trash
- Void
- Soul Core
- Burst
- Spirits
- Ultimates
- Braves
- Nexus
- Ataque e bloqueio
- Pagamento de custos
- Reduction Symbols
- Resolução manual de efeitos
- Histórico de ações
- Log da partida

Novas mecânicas continuam sendo implementadas conforme o projeto evolui.

---

## Deck Builder

O Deck Builder permite criar e organizar decks diretamente dentro do simulador.

Recursos atuais incluem:

- Busca de cartas
- Filtros
- Controle de quantidade
- Validação de deck
- Carta de capa
- Biblioteca de decks
- Importação de decks
- Exportação de decks

---

## Database de cartas

A database do simulador está em expansão constante.

As cartas são organizadas por coleção e preparadas para exibição em:

- Português do Brasil
- Inglês

Novas coleções são catalogadas gradualmente para ampliar cada vez mais o número de cartas disponíveis no simulador.

---

## Partidas Online

O modo Online permite que dois jogadores se enfrentem em tempo real.

Entre os recursos disponíveis:

- Partidas 1v1
- Criação de salas privadas
- Entrada por código
- Matchmaking
- Escolha de deck
- Cor personalizada de jogador
- Sincronização da partida
- Reconexão de sessão
- Mão do oponente oculta
- Chat
- Log de ações

A posição do jogador local permanece sempre na parte inferior da arena para facilitar a leitura da partida.

---

## Perfil e personalização

O simulador também possui um sistema de perfil para tornar a experiência mais pessoal.

É possível configurar:

- Nome de jogador
- Nome de usuário
- Foto de perfil
- Banner
- Biografia
- Cor de jogador
- Tema da interface

---

## Desenvolvimento contínuo

O Battle Spirits Eternal Simulator ainda está em desenvolvimento.

Alguns efeitos e mecânicas podem exigir resolução manual enquanto o suporte automático é ampliado.

Entre os principais objetivos do projeto estão:

- Expandir a database de cartas
- Implementar mais efeitos automaticamente
- Melhorar a fluidez das partidas
- Adicionar suporte a mais mecânicas
- Aprimorar o modo Online
- Melhorar continuamente a interface
- Tornar o simulador cada vez mais completo e acessível
