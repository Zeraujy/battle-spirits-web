# Battle Spirits: KAIHOU! Simulator — v5.0.0 Final QA

Status: release candidate validated for final packaging.

## Authority guarantees

- Server owns authoritative game state and stateVersion.
- Server validates and locks decks before Online matches.
- Server owns Ranked result, RP delta and abandon/disconnect outcome.
- Client cannot submit winner or rating changes.
- Reconnect restores the server snapshot and never reconstructs game state from client storage.
- Match history for Online/Ranked is generated from authoritative MatchSession state.

## Security guarantees

- Opponent hidden zones are sanitized server-side.
- Online events are protected by rate limits and payload ceilings.
- Reconnect tokens use constant-time equality checks.
- Cross-mode activity conflicts are rejected before creating rooms or joining queues.
- Server-only credentials remain outside the frontend.
