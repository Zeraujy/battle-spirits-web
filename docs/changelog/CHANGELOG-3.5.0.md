# Battle Spirits Eternal Simulator v3.5.0

## Unified Eternal Interface

Grande redesign visual das telas de sistema para aproximá-las da identidade cinematográfica estabelecida pela Home e pelo Match Setup.

### Redesign
- Meus Decks: novo fundo cinematográfico, cabeçalho à esquerda, estatísticas mais leves e biblioteca de decks com menos aparência de dashboard.
- Deck Builder: painéis translúcidos, cabeçalho alinhado à identidade do menu e interface de edição preservada.
- Configurações: navegação lateral inspirada no Menu Principal, seletor ativo com barra branca e conteúdo simplificado visualmente.
- Conta/Perfil: mesma linguagem de fundo, títulos e superfícies do restante do jogo.
- Loja: apresentação cinematográfica própria mantendo a área como fundação futura.
- Modais de Novo Deck / Deck Pronto também foram ajustados ao novo sistema visual.

### Perspectiva 3D
- O efeito 3D/Perspectiva do modal de detalhes da carta foi preservado integralmente.
- Capas na biblioteca de decks, preview de prebuilt e capa atual do Deck Builder recebem uma perspectiva mais sutil baseada no ponteiro.

### Sem mudanças de regra
Nenhuma mudança em Rules Engine, Eternal CPU, AI Debugger, Online, matchmaking, Supabase, database ou regras de Battle Spirits.
