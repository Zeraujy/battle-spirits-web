# Battle Spirits Eternal Simulator v3.1.2 — Eternal Monochrome Complete

Data: 23/09/2026

## Paleta unificada
- Todas as folhas de estilo da aplicação foram revisadas para remover azul, amarelo, dourado, ciano, verde e vermelho usados apenas como decoração.
- Configurações, Deck Builder, biblioteca de decks, lobby Online, setup Local, Perfil, Conta, modais e painéis auxiliares agora seguem preto, branco e grafite.
- Dentro da partida, Sequência Eternal, decisões de efeito, Brave/Ultimate, Trigger Counter, resultado da partida, combate, setas e estados auxiliares também seguem a identidade monocromática.
- Cores de jogador padrão e opções do lobby foram convertidas para uma escala de cinza.
- Cores decorativas de decks predefinidos foram neutralizadas.

## Exceções de gameplay
- **Core regular:** azul, incluindo os Cores posicionados nas cartas e os Cores de Life.
- **Soul Core:** vermelha.
- Os indicadores/orbes que representam diretamente as cores/símbolos das cartas continuam coloridos.
- A arte original das cartas permanece sem qualquer filtro ou alteração.

## Migração
- Usuários no preset `recommended:eternal` continuam recebendo automaticamente o tema Eternal atual.
- Cores antigas de jogador salvas no Eternal são migradas para tons neutros.
- Temas alternativos continuam disponíveis como escolha manual e não alteram o padrão Eternal.

## Compatibilidade
- Nenhuma regra do Rules Engine foi modificada.
- Nenhuma dependência nova foi adicionada.
