# Battle Spirits Eternal Simulator v3.4.1b

## Match Setup Menu Consistency

Hotfix visual focado em deixar as telas de seleção de partida coerentes com o Menu Principal.

### Alterações

- O bloco de título, status e opções dos modos passa para o lado esquerdo da tela.
- Os botões usam a mesma tipografia e comportamento visual do Menu Principal.
- Jogo Livre não repete mais Trocar deck P1/P2 no menu; os controles ficam abaixo dos jogadores.
- Eternal CPU não repete mais Trocar seu deck / Trocar deck da CPU no menu.
- Online Normal não repete mais Trocar deck no menu e remove o seletor de cor da tela de preparação.
- Ranked não repete mais Deck ranqueado no menu.
- O seletor rápido de deck continua disponível pelos controles abaixo dos retratos.

### Compatibilidade

Sem mudanças em gameplay, Rules Engine, IA, matchmaking, Socket.IO, Supabase ou database.
