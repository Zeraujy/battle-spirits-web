# Documentation

The documentation tree contains current maintenance references only. Historical phase, batch and release-status documents are not part of the active architecture.

## Areas

- `architecture/` — project and script/data layout.
- `arena/` — current Arena architecture, validation scope and parallel redesign foundation.
- `card-database/` — card catalog maintenance.
- `changelog/` — concise project history.
- `deployment/` — deployment workflow.
- `development/` — local development and testing.
- `effects/` — current effect-engine architecture and validation.
- `game-rules/` — rule coverage and ranked-season references.
- `maintenance/` — repository maintenance policy.
- `online/` — current multiplayer architecture and validation.
- `shop/` — shop-content maintenance.

Executable audits and tests are the canonical proof of behavior. Documentation must not be used as a substitute for runtime or source validation.
