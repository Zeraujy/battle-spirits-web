# Arena Validation

Arena validation is performed by executable audits under `scripts/audits/arena/` rather than historical phase documents.

The audits cover:

- presentation boundaries;
- battlefield and HUD integration;
- resources and hand presentation;
- card preview and context presentation;
- contextual actions and phase tracking;
- targeting and motion;
- overlays and event feedback;
- responsive and performance guards;
- release readiness;
- visual identity and resource presentation;
- combat layout stability.

Historical phase documents are intentionally not required by the validation pipeline. The source code and automated audits are the canonical validation targets.
