# v4.9.1 — Arena Visual Identity Alignment / Steps 05–07

## Scope

This block aligns the contextual Arena UI with the shared interface language introduced in Block 01–03.

Aligned components:

- `ContextPanel`
- `CardPreview`
- `ActionBar`
- `PhaseTracker`

## Visual rule

The implementation follows the project rule:

> Shared identity, lower visual density.

The Arena consumes the same shared surface, border, text, blur, shadow, radius and interaction tokens used as the design-system foundation, while keeping cards as the strongest visual layer.

## ContextPanel / CardPreview

- Uses `--surface-glass`, shared borders and shared blur.
- Keeps the selected card as the focal element.
- Metadata uses quiet neutral surfaces instead of strong pills.
- Hover preview uses the elevated surface language without introducing gameplay color.

## ActionBar

- Remains contextual and hidden when no contextual actions exist.
- Buttons use neutral surfaces and shared interaction states.
- `primary-btn` is intentionally only slightly stronger than secondary actions.
- No new action or gameplay condition was introduced.

## PhaseTracker

- Uses the shared glass surface and border language.
- Current phase is communicated primarily through contrast and typography.
- Glow intensity was reduced to keep attention on cards and battlefield state.
- `ADVANCE_PHASE` behavior and callback ownership are unchanged.

## Safety boundaries

No changes were made to:

- `src/game/`
- `src/online/`
- `src/services/`
- `server/`
- reducers or gameplay actions
- action legality
- phase progression logic

The changes in this block are CSS-only presentation changes plus QA documentation/audit coverage.
