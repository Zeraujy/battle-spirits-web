# Project Structure — v4.8.1

- `src/` — frontend Web.
- `public/` — imagens, cartas e configuração pública.
- `server/` — multiplayer remoto.
- `supabase/` — schema, políticas e migrações cloud.
- `scripts/card-db/` — manutenção do catálogo.
- `scripts/*.mjs` — verificadores e auditorias do projeto.
- `docs/` — documentação ativa.
- `resources/` — fontes de dados/assets usadas para manutenção do catálogo.

Não existem fluxos específicos de sistema operacional no projeto oficial.
