# v5.1.0 — Phase 0–1 Foundation

## Phase 0 — Full Card Effects Audit

Added a deterministic audit for the runtime gameplay catalog.

Commands:

```bash
npm run effects:audit
npm run effects:audit:check
```

Generated outputs:

- `docs/effects/CARD-EFFECT-COVERAGE.md`
- `data/effect-coverage.json`

The audit distinguishes fully automated, partial, manual, unsupported trigger/condition/action, unstructured text, and explicit no-effect cards.

## Phase 1 — Canonical Event Model

Added `src/game/effectEngine/canonicalEvents.js` as the single canonical vocabulary for effect timings/events. Existing aliases remain backward compatible through `normalizer.js`.

A canonical event can exist before the runtime dispatches it. The audit intentionally treats canonical-but-undispatched events as coverage gaps.
