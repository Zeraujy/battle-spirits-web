# v5.1.0 — Phase 18: Effect Resolution UI

Phase 18 expands the Arena Effect Resolution overlay so structured decisions no longer need to fall back to the legacy manual panel.

## Arena UI coverage

- contextual source/effect header;
- highlighted field targets;
- Hand / Trash / Deck card picker;
- Yes/No and multi-option choices;
- multiple-card counters and BP limits;
- explicit card ordering controls;
- Core-distribution steppers with authoritative total validation;
- waiting state for the non-controlling Online player.

The legacy Manual Resolution flow remains available only for effects that the schema still cannot represent.
