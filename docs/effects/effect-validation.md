# Effect Validation

Effect validation is executable and source-driven.

The current validation pipeline covers:

- card-effect coverage consistency;
- schema and trigger dispatch;
- queues, targeting and conditions;
- core actions, modifiers and durations;
- replacement/prevention and battle triggers;
- Magic, Burst and Brave behavior;
- advanced decisions;
- authoritative ordering;
- Starter Deck readiness;
- migration readiness;
- generated card regression scenarios;
- final mechanics and release QA commands.

Generated status documents such as card coverage and Starter Deck readiness are outputs of current audits, not historical release-phase requirements.
